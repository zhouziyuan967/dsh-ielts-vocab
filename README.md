# dsh-ielts-vocab

雅思单词插件：每日核心词 + 间隔重复复习，以低饱和度「背景层」安静地显示在 Harness Web UI 中。

## 功能

- **背景词层**：今日单词以浅色衬线字体铺在界面背景，不遮挡操作；右上角小胶囊显示今日已复习数量。
- **可拖动胶囊**：按住胶囊即可拖到任意位置，位置会保存；设置里可恢复默认位置。
- **每日计划**：默认每天 20 个新词，可在插件设置里改为 10/15/20/30/50；到期复习优先出现。
- **间隔重复**：忘记（10 分钟后）、模糊（1 天）、认识（按记忆曲线）、太简单（更久）。
- **词卡**：音标、词性、中英释义、雅思例句与中文翻译、话题标签。
- **测验**：从学过的词中随机抽 5 题选择题。
- **AI 记忆法**：卡片上的按钮会调用当前默认模型生成记忆法（关闭 reasoning，节省额度）；失败时可复制提问到对话继续。
- **智能体工具**：`ielts_vocab`（today / word / review / quiz / note / ai / stats），Host 与 UI 共用同一份学习记录。

## 数据

学习记录保存在当前 profile 下：`<profile>/ielts-vocab/state.json`。
词库内置在 `words.js`，共 204 个雅思核心词。
